# ShopHub - Modern E-Commerce Store

## 🚀 Features

### Technology Stack
- **HTML5** - Semantic markup
- **CSS3** - Modern styling
- **Tailwind CSS** - Utility-first CSS framework
- **JavaScript ES6+** - Modern JavaScript features
- **React.js** - Component-based UI library
- **React Router** - Client-side routing

### Pages
1. **Home** - Landing page with hero section and features
2. **Products** - Product listing with search functionality
3. **Product Details** - Dynamic product details page
4. **Cart** - Shopping cart with quantity management
5. **Wishlist** - Save favorite products
6. **Login** - User login form (UI only)
7. **Sign Up** - User registration form (UI only)
8. **About** - Company information
9. **Contact** - Contact form with business info
10. **404** - Custom error page

### API Integration
- **DummyJSON Products API** - Real product data
- Proper loading states
- Error handling with retry functionality
- Uses `fetch()` API
- React hooks: `useEffect`, `useParams`, `useState`

### LocalStorage Features
- **Cart Management** - Persistent shopping cart
- **Wishlist** - Save favorite products
- **Login Data** - Demo login persistence
- **Sign-Up Data** - Demo registration persistence

### Design Features
- **Modern Gradient Background** - Purple to pink gradient
- **Glassmorphism** - Frosted glass effect
- **Smooth Animations** - Fade-in and slide-in effects
- **Responsive Design** - Mobile-first approach
- **Custom Scrollbar** - Styled scrollbar
- **Hover Effects** - Interactive elements
- **Loading States** - Skeleton screens
- **Error States** - User-friendly error messages

## 📦 Installation

```bash
npm install
npm start
```

## 🌐 Deployment

### GitHub
```bash
git clone https://github.com/rahul700raj/modern-ecommerce-store.git
cd modern-ecommerce-store
npm install
npm start
```

### Netlify
1. Connect your GitHub repository
2. Build command: `npm run build`
3. Publish directory: `build`
4. Deploy!
